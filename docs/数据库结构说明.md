# 数据库结构说明

本项目使用 Dexie.js 管理浏览器 IndexedDB，数据库名为 `ai_role_chat_system`。

主要表：

- `globalAIConfigs`：只保存一个全局 API Key。默认使用 `sessionStorage`，用户勾选“记住我的 API Key”后才写入 IndexedDB。该表永远不进入备份或云端同步数据。
- `characters`：保存角色基础资料、性格资料、故事资料和当前服装引用。
- `worlds`：保存每个角色对应的世界观资料。
- `images`：保存角色头像、全身图等压缩后的 Data URL 图片。
- `outfits`：保存服装资料、服装图片和当前使用状态。
- `conversations`：保存聊天会话。
- `messages`：保存聊天消息、生成状态、模型和编辑标记。
- `memories`：保存长期记忆，包含类型、重要程度、固定、启用和是否允许 AI 使用。
- `preferences`：保存聊天、记忆和界面偏好。
- `syncConfigs`：保存用户自己的云端服务器地址、访问密钥、同步路径和最近同步时间。同步数据本身不包含 API Key。

统一备份类型为 `BackupData`，包含角色、世界观、图片、服装、会话、消息、长期记忆和用户偏好设置，不包含 API Key、全局 AI 配置或云端访问密钥。

所有业务数据均包含 `id`、`createdAt`、`updatedAt`。
